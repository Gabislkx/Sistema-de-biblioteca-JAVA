# SISTEMA DE BIBLIOTECA

### Descrição
 Sistema de Biblioteca focado na modelagem de materiais e regras de empréstimo. Apesar de ser uma aplicação enxuta, ela foi essencial para colocar em prática pilares importantes do desenvolvimento back-end:
Interfaces: Padronizando comportamentos com a interface Emprestavel.
Herança e Sobrescrita: Especializando prazos distintos para Livro (14 dias) e Revista (7 dias) a partir da classe Material.
Sobrecarga e Polimorfismo: Criando métodos flexíveis para exibir informações e manipulando diferentes objetos de forma unificada.
